## 화면에 사용하는 내용의 근거

| 프로그램의 설명·관계 | 교과서 위치 | 대조 결과 |
|---|---|---|
| 전지 내부에 전하 흐름을 방해하는 내부 저항 r이 있다. | 167쪽, 기전력 절 본문 | 본문 확인 |
| 실제 전지를 기전력 ε와 직렬 내부 저항 r로 나타낸다. | 167쪽 말미, 168쪽 그림 Ⅲ-25(a)의 점선 경계 안 | 본문과 그림 확인 |
| 내부 저항이 0인 이상적인 전지는 단자 전압과 기전력이 같다. | 167쪽 기전력 절 | 본문 확인 |
| 방전 방향으로 기전력 부분을 지날 때 ε만큼 상승하고 내부 저항에서 Ir만큼 감소한다. | 168쪽 첫 문단, 그림 Ⅲ-25(b) | 본문·전위 그래프 확인 |
| 단자 전압 V = ε − Ir | 168쪽 식 (Ⅲ. 3-12) | 수식·전위 그래프 확인 |
| 단일 외부 저항 R에 연결한 전류 I = ε/(R+r) | 168쪽 식 (Ⅲ. 3-13)–(Ⅲ. 3-14) | 수식 확인 |
| 전력 수지 εI = I²R + I²r | 168쪽 식 (Ⅲ. 3-15) | 수식 확인; 167쪽 식 (Ⅲ. 3-11)의 P = I²R과도 대조 |

기호 ε는 교과서의 기전력 E(도판에서는 ε)와 같은 뜻으로 통일했다. 웹 화면의 V는 전지의 **단자 전압**, ε는 **기전력**이다. 내부 전류는 전체 회로 전류 I₁이므로 화면에서는 I₁r와 I₁²r로 쓴다.

168쪽 식 아래 본문에서 외부 저항의 전력 항이 I²r로 표기된 부분은 식 (Ⅲ. 3-15)의 I²R과 불일치한다. 구현은 이 문장의 혼동 가능한 기호를 그대로 옮기지 않고, 명확한 식 (Ⅲ. 3-15)와 167쪽 식 (Ⅲ. 3-11)을 근거로 **외부 I²R, 내부 I²r**를 사용했다.

## 교과서의 내용과 프로그램의 적용을 구분

**교과서에서 직접 확인한 내용**은 위 표에 한정한다. 아래는 그 관계를 기존 회로에 적용하거나 시각화한 프로그램 설계이며, 교과서에 같은 3D 화면이나 같은 수치 예제가 실려 있다는 뜻이 아니다.

- 기존 외부 회로의 등가 저항은 R외부 = R₁ + Rₚ이다. Rₚ는 닫힌 스위치에서 R₂R₃/(R₂+R₃), R₃ 가지가 열리면 R₂이다.
- 교과서 식의 R에 R외부를 대입하여 I₁ = ε/(r+R₁+Rₚ), 단자 전압 V = ε−I₁r로 계산한다.
- 내부를 지나는 고리에도 내부 전압 강하 −I₁r를 포함한다. 순회를 반대로 하면 각 변화의 순서와 부호를 반대로 한다.
- 내부 저항 슬라이더 0–5 Ω, ε = 12 V 및 R외부 = 7 Ω 등의 수치는 프로그램의 조작 범위와 예시이다. 교과서의 실측 자료가 아니다.
- 3D의 반투명 외피, 기전력 부분과 저항 모양은 **그림 Ⅲ-25의 등가 모형을 입체화한 설명용 표상**이다. 실제 전지에 외장 저항기 같은 부품이 들어 있다는 뜻이 아니다.
- 원자료에서 확인하지 않은 전해질·전극 재료·화학 반응·미시적 내부 저항 원인은 추가하지 않았다. 이 화면은 실제 전지의 화학적 내부 단면을 제공하지 않는다.
- 정상 상태의 방전 회로, 일정한 기전력과 내부·외부 저항을 가정한다. 충전·온도 변화·과도 현상을 모사하지 않는다.

## 구현 검증

1. r = 0의 결과는 기존 이상적 전지의 결과와 같다.
2. ε = 12 V, R외부 = 7 Ω, r = 1 Ω이면 I₁ = 1.50 A, Ir = 1.50 V, 단자 전압 = 10.50 V이다.
3. 같은 예에서 εI₁ = 18.00 W, 외부 저항 전력 = 15.75 W, 내부 저항 전력 = 2.25 W이며 수지가 맞는다.
4. 여러 기전력·저항·스위치 조건에서 전하·고리 전위·내부를 포함한 총 전력 보존과 역방향 부호를 검사한다.
5. 브라우저에서는 내부 저항/배터리 클릭, 2D 등가도, 3D 투명 외피와 내부 확대, 닫기, 슬라이더 연동, 내부 저항을 포함한 기록·내려받기, 모바일 배치와 이전 기록 형식 호환을 검사한다.
