# VOID FRONT

브라우저에서 플레이하는 싱글 플레이 실시간 전략 게임입니다. 별도 설치, 로그인, 외부 에셋 요청 없이 동작합니다. 전장·건물·유닛·미네랄은 Canvas로 직접 그리며 효과음은 Web Audio로 합성합니다.

## 실행

저장소에서 `npm start`를 실행합니다. Python 3 정적 서버가 3000번 포트를 사용합니다. 첫 화면에서 **작전 시작**을 누르세요. 기존 과학 탐구실은 `learning.html`에 보존되어 있습니다.

## 목표와 시스템

적 지휘소를 파괴하면 승리합니다. 자신의 지휘소를 잃으면 패배합니다. 적은 38초마다 점점 강해지는 공격 부대를 증원합니다.

- 작업자: 미네랄 채취, 건설. 처음 6명은 자동 채취합니다. 미네랄을 가져와야 자원이 증가합니다.
- 지휘소: 작업자 생산, 기본 보급 제공.
- 병영: 돌격 보병 생산.
- 보급소: 최대 보급 +8.
- 정제소: 완공 후 가스 자동 생산.
- 군수 공장: 병영 완공 후 건설 가능. 가스와 미네랄로 공성 전차 생산.
- 자동 포탑: 주변의 적을 공격.
- 전차: 긴 사거리, 느린 연사, 범위 피해.

## 조작

- 좌클릭: 선택. 드래그: 여러 유닛 선택. Shift: 추가 선택. 더블클릭: 화면 내 같은 종류 선택.
- 우클릭: 이동, 적 공격, 미네랄 채취, 미완성 건물 건설 재개.
- A → 좌클릭: 공격 이동. S: 정지. Esc / 건설 중 우클릭: 명령 취소.
- Ctrl+1/2/3: 부대 저장. 1/2/3: 부대 선택.
- WASD / 방향키 / 화면 가장자리: 카메라 이동. 단축 명령과 겹칠 때 A는 공격 명령, S는 정지 명령을 우선합니다.
- 마우스 휠: 확대·축소. Space: 기지 이동. 미니맵 클릭: 카메라 이동.
- 지휘소 W: 작업자. 병영 M: 보병. 공장 T: 전차.
- P: 일시정지. 소리 버튼: 효과음 활성화.

PC 마우스·키보드 조작을 기준으로 합니다. 작은 화면에서 UI는 조정되지만 완전한 모바일 터치 조작은 제공하지 않습니다. 단일 진영 대 AI 전투이며 원작의 세 종족, 캠페인, 멀티플레이, 전체 기술 체계는 포함하지 않습니다.

## 검증

`node --check rts.js`로 구문을 검사합니다. `node tests/rts.test.cjs`는 자원·건설·가스·생산 제한·전투 피해·승패·재시작의 6개 시뮬레이션 검증을 실행합니다. Playwright와 시스템 Chromium이 있으면 서버 실행 후 `python3 tests/rts_browser.py`로 실제 채취·생산·건설·선택·이동·공격 이동·부대 저장·일시정지·적 증원·재시작을 확인합니다. 스크린샷은 `/tmp/voidfront-checks`에 저장됩니다. 기존 `npm test`는 과학 탐구실 물리 계산 테스트입니다.
