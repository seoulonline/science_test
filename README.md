# 사이언 · 키르히호프 탐구실

**개념을 이해하고, 증거로 설명하고, 새 상황으로 옮기는 과학.**

고등학생을 위한 한국어 웹 학습 프로그램입니다. 사용자 제공 전자기학 교과서와 과학철학·개념 기반 탐구 자료를 참고해, 키르히호프 법칙을 전하량 보존과 에너지 보존의 관점에서 탐구합니다.

## 실행

저장소 디렉터리에서 실행합니다. 애플리케이션은 추가 패키지 설치·API·로그인 없이 작동합니다.

```sh
npm start
```

Python 3의 정적 서버가 **3000번 포트**에서 실행됩니다. npm을 사용하지 않아도 다음 명령으로 같습니다.

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

서버가 실행된 상태에서 브라우저로 3000번 포트를 엽니다. JavaScript 모듈을 사용하므로 HTML 파일을 `file://`로 직접 열지 않습니다. Node.js는 물리 계산 검증에만 필요합니다. 빌드 단계는 없습니다.

## 학습 흐름

1. **개념 만나기** — 전하·전류·전위차·에너지를 구분하고 첫 생각을 기록합니다.
2. **탐구하기** — 먼저 예측한 뒤 전압·저항·스위치를 조작합니다. 서로 다른 조건을 기록·비교하고 개념 사이의 관계를 문장으로 설명합니다.
3. **전이하기** — 생활 속 저전압 조명, 낯선 측정 자료, 축적되는 물탱크에 일반화를 적용하고 조건을 검토합니다.
4. **성찰하기** — 예측과 지금의 설명, 생각을 바꾼 증거, 모형의 한계와 다음 질문을 정리합니다.

[프로그램 개요 및 교사용 안내](docs/learning-design.md)에 KUD 목표, 차시별 활동, 평가 준거, 출처를 정리했습니다. 웹 화면의 ‘수업 안내와 자료’에도 요약 안내가 있습니다.

## 가독성과 과학철학 활동

학생용 본문을 17–18px로 표시하고 입력란·설명·버튼을 확대했습니다. 모바일에서는 조작 영역을 한 열로 배치하고, 회로를 좌우로 살펴볼 수 있습니다. 각 단계에서 관찰과 해석 구분, 경쟁 설명을 가르는 예측, 가정과 독립 검증, 증거에 따른 생각 수정을 다룹니다. 작성한 이유는 탐구 노트와 내려받기에 포함됩니다.

## 시뮬레이션

- 기전력 ε와 내부 저항 r을 갖는 전지 → 외부 공통 저항 R₁ → 병렬 가지 R₂·R₃. R₃ 가지에 스위치가 있습니다.
- 기전력 2–24 V, 내부 저항 0–5 Ω, 각 외부 저항 1–20 Ω을 조작합니다. r = 0이 기본값이며 기존 이상적 전지와 같습니다.
- 관습적 전류 방향의 점 표상, 분기점 전류 관계, 선택한 고리의 전위 변화와 순회 방향을 비교합니다.
- 열린 스위치를 지나는 경로는 닫힌 도전 고리로 표시하지 않습니다. 전류가 0이어도 열린 스위치 양단에 전압이 있을 수 있음을 안내합니다.
- 전지 내부 저항을 포함합니다. 도선 저항, 계측기 영향, 온도와 과도 현상은 생략합니다. 이는 실제 회로 측정이나 자유 배선 편집기가 아닌 정해진 회로 구조의 학습 모형입니다.
- 계산 결과를 보존 법칙에 대한 독립적인 실험 증거로 취급하지 않도록 명시했습니다.

## 3D 입체 회로

시뮬레이션 위의 **3D 입체 회로** 버튼으로 전환합니다. 같은 물리 계산으로 전지·저항·스위치와 전류를 입체로 표현하며, 슬라이더와 스위치·기록 기능을 함께 사용합니다.

- 드래그 또는 방향키: 회전
- 마우스 휠·두 손가락 벌리기 또는 +/− 버튼: 확대·축소
- 시점 초기화·위에서 보기 버튼 제공
- 재생·정지, 움직임 줄이기 설정이 2D와 3D에 함께 적용
- WebGL 2가 없거나 3D 연결이 끊기면 2D로 복귀하여 기존 기능 유지

높이는 전위를 뜻하지 않습니다. 새로운 전자기장 수치 해석이 아니라 같은 정상 직류 회로의 입체 표상입니다. 실제 3D 렌더링은 MIT 라이선스의 Three.js 0.180.0을 사용하며, 배포 파일과 라이선스를 `vendor/three/`에 포함했습니다. CDN 요청과 설치 과정 없이 정적 서버에서 실행합니다.

## 배터리 내부 보기 · 교과서 근거

**내부 저항 r · 배터리 안 살펴보기**를 누르거나 2D·3D의 배터리를 클릭하면 전지 내부의 등가 모형을 살펴볼 수 있습니다. 3D 내부 보기에서는 외피를 반투명하게 하고 기전력 부분과 내부 저항을 확대합니다. ‘시점 초기화’로 전체 회로에 돌아갑니다.

기전력 ε와 내부 저항 r의 직렬 모형은 교과서 **167–168쪽(PDF 30–31쪽)**에서 본문·그림·수식을 직접 대조했습니다. 실제 화학적 단면이나 전지 안의 별도 저항기 부품을 뜻하지 않습니다. 기전력과 단자 전압을 구분하며 내부 저항을 조작하면 전류, V = ε−I₁r, 내부 전압 강하와 전력 I₁²r을 다시 계산합니다. 관찰 기록과 고리 전위 변화에도 반영합니다.

[교과서 대조 기록](docs/textbook-verification.md)에 출처·식 번호·확인 방법, 교과서 내용과 프로그램 적용의 구분을 정리했습니다.

## 사이드바 수정

사이드바의 **사이드바 편집** 또는 상단의 **문구 편집**에서 사이트 이름·소개·메뉴·주제·단원·안내 메시지·프로필을 수정합니다. 저장 전에는 적용되지 않으며, 취소하거나 기본 문구를 불러올 수 있습니다. 메뉴의 기능과 관찰 기록은 유지됩니다.

브라우저 편집 내용은 `saien-sidebar-v1`에 저장되어 **이 기기에만 적용**됩니다. 로그인·관리자 서버·모든 사용자에게 배포하는 기능은 없습니다. 모든 사용자에게 적용할 기본 문구는 [sidebar-config.js](sidebar-config.js)의 `sidebarFields`에서 변경하고 배포하면 됩니다. 기존 브라우저의 편집값이 기본 문구보다 우선하므로, 새 기본값을 사용하려면 편집 창에서 기본 문구를 불러와 저장합니다. 사용자 입력은 HTML로 실행하지 않고 글자로 표시합니다.

## 기록과 개인정보

관찰 기록과 서술형 초안은 `localStorage`의 `saien-lab-v1`에 저장됩니다. 브라우저·출처(origin)별 저장이며, 기기 간 동기화나 교사 전송, 서버 저장은 없습니다. 기기 저장을 지우면 기록이 사라집니다. Markdown 파일로 내려받아 보관할 수 있습니다. 저장 공간이 차단되거나 부족하면 경고합니다. 자동 서술형 채점은 하지 않습니다.

외부 웹 폰트·분석 도구·네트워크 API 요청이 없습니다. 시스템의 한국어 글꼴을 사용합니다.

## 검증

```sh
npm test
```

Node.js 내장 테스트 러너로 8개 검증을 실행합니다. 알려진 회로의 해, 가지 개방과 상호작용, 순회 부호, 내부 저항을 포함한 864개 조건 조합에서 전하·전위·전력 보존, 잘못된 입력을 확인합니다.

브라우저 기능 검증은 Python Playwright와 Chromium이 설치된 환경에서, 서버를 켠 다음 실행합니다.

```sh
python3 tests/browser_smoke.py
python3 tests/browser_3d_sidebar.py
python3 tests/browser_battery.py
```

추가 검증 도구가 없는 환경에서는 `python3 -m pip install playwright pillow`와 브라우저 설치가 필요합니다. 기본 Chromium 경로는 `/usr/bin/chromium`이며 `CHROMIUM_PATH`로 바꿀 수 있습니다. `SAIEN_TEST_URL`로 검사 대상 주소를 지정합니다. 일반 화면 스크린샷은 `/tmp/saien-checks`, 3D 스크린샷은 `/tmp/saien-3d-checks`, 내부 보기 스크린샷은 `/tmp/saien-battery-checks`에 생성됩니다. 3D 검증은 헤드리스 Chromium에서 소프트웨어 WebGL을 활성화해 실제 렌더링·시점 조작·공유 계산을 검사하며, WebGL 비활성 환경과 렌더링 연결 중단의 2D 복귀도 검사합니다. 이 소프트웨어 렌더링 옵션은 테스트 실행에만 사용됩니다.

## 파일 구성

- `index.html`, `style.css` — 반응형 학습 화면
- `app.js` — 학습 활동, 회로 표상, 기기 저장·내보내기
- `physics.js` — UI와 분리한 정상 직류 회로 계산
- `circuit-3d.js`, `vendor/three/` — 필요할 때 불러오는 WebGL 입체 회로
- `sidebar.js`, `sidebar-config.js` — 사이드바 편집과 공통 기본 문구
- `tests/` — 계산 및 브라우저 기능 검증
- `docs/learning-design.md` — 프로그램 개요·수업 운영·자료 근거

교과서와 책은 요약·재서술했으며 원본 PDF나 도판을 배포하지 않습니다. 회로도와 문제는 이 프로그램용으로 새로 작성했습니다.
